# First Coding-Agent Prompt

Create the initial ExoSwarm repository scaffold described by `docs/03_REPO_SCAFFOLD.md`. Establish
the package boundaries, typed contracts, configuration, runnable FastAPI and Next.js smoke paths,
result-lock/catalog-gate policy, artifact directories, CI, and boundary tests.

This task is scaffold-only. Scientific tools and model/catalog clients must return or raise an
explicit not-implemented state. Do not add live TESS downloads, numerical astronomy algorithms,
live inference, live catalog lookups, fake scientific values, or polished demo behavior. Read
`AGENTS.md` and `docs/00_SOURCE_OF_TRUTH.md` through `docs/12_SKILLS_GUIDE.md` before editing.

Completion requires exact verification of backend tests/lint/import, frontend lint/type/build,
blindness and lock invariants, plus a report of any dependency limitations. Stop before Phase 1.
