# ExoSwarm Context-Pack Manifest

Use these files as the coding-agent context for creating the repository scaffold.

## Root

- `README.md` - repository README.
- `AGENTS.md` - repository-wide AI coding-agent contract.
- `FIRST_AGENT_PROMPT.md` - the first prompt to give the coding agent.

## Docs

- `docs/00_SOURCE_OF_TRUTH.md` - source requirements vs derived scaffold conventions.
- `docs/01_PROJECT_BRIEF.md` - product claim, scientific boundary, demo proof.
- `docs/02_ARCHITECTURE.md` - system/data-flow/trust architecture.
- `docs/03_REPO_SCAFFOLD.md` - target repository tree and package boundaries.
- `docs/04_TECH_STACK.md` - approved 48-hour technology stack and exclusions.
- `docs/05_AGENT_RUNTIME.md` - roles, state, loop, validation, context, traces.
- `docs/06_SCIENCE_CONTRACTS.md` - deterministic science and tool-result contracts.
- `docs/07_DATA_ARTIFACTS_BLINDING.md` - cached data, ledger, lock/hash/reveal.
- `docs/08_API_EVENTS.md` - derived REST + SSE scaffold contracts.
- `docs/09_UI_GUIDE.md` - mission-control UI structure and visualization constraints.
- `docs/10_TESTING_EVALS.md` - tests, scientific validation, agent evals, release gates.
- `docs/11_48H_SCOPE_AND_BUILD_ORDER.md` - P0/P1/P2 scope and phased implementation.
- `docs/12_SKILLS_GUIDE.md` - index for the supplied skill files.
