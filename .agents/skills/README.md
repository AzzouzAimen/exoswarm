# Included Skills

This index mirrors the skill directories under `.agents/skills/`. Use the narrowest skill that owns the task.

- `build-mission-control-ui` - Build or modify ExoSwarm's mission-control frontend and scientific storytelling UI, including visualizations, investigation timelines, evidence boards, result locking, catalog reveal, and demo-facing states.
- `debugging-wizard` - Investigate errors, stack traces, log failures, crashes, and unexpected behavior using systematic root-cause analysis before applying a fix.
- `design-agent-tools` - Design, implement, or review AI-agent tools, including schemas, permissions, return payloads, typed failures, side effects, and token efficiency.
- `engineer-agent-context` - Design the runtime context supplied to an agent, including context budgets, just-in-time retrieval, evidence trimming, provenance, compaction, and stale-context handling.
- `engineer-agent-harness` - Build or strengthen the control system around an agent, including instructions, permissions, routing, persistence, validation, tracing, recovery, evaluation gates, and approvals.
- `engineer-agent-loop` - Implement or review bounded agent-loop behavior, including state transitions, retries, budgets, termination, idempotency, resumability, and recovery.
- `engineer-agent-system` - Design or redesign agentic application architecture, including model boundaries, topology, state, routing, approvals, observability, and failure handling.
- `eval-engineering` - Create, run, and audit Harbor evaluations, tasks, verifiers, and controlled agent environments one case at a time.
- `evaluate-agent-system` - Build or improve evaluations for agentic systems using traces, scenario suites, deterministic checks, trajectory metrics, qualitative judges, cost, latency, and regression gates.
- `harden-demo` - Harden the finished ExoSwarm demo for repeatability, cached/offline operation, reset behavior, model/API failure recovery, and result-lock integrity.
- `implement-feature` - Implement a non-trivial ExoSwarm feature when no narrower skill owns the work, including the contract, code, tests, and verification.
- `implement-science-tool` - Implement or modify deterministic ExoSwarm astronomy computation and scientific result contracts with explicit units, failures, and provenance.
- `langgraph-fundamentals` - Use when writing any LangGraph code, including `StateGraph`, state schemas, nodes, edges, `Command`, `Send`, invocation, streaming, and error handling.
- `orchestrate-investigation` - Implement or modify ExoSwarm's scientific-agent investigation loop, including hypotheses, bounded experiments, permissions, evidence, audit records, and stopping rules.
- `prompt-engineer` - Write, refactor, and evaluate prompts, structured output schemas, rubrics, few-shot examples, and prompt test suites.
- `python-pro` - Use for Python 3.11+ implementation requiring type safety, async patterns, robust errors, pytest, mypy, black, or ruff.
- `reference-exoplanet-projects` - Route ExoSwarm science, investigation, and evaluation work to indexed SHERLOCK/WATSON, ASTER, or Stargazer references.
- `the-fool` - Challenge ideas, plans, decisions, and proposals through devil's-advocate review, pre-mortems, red teaming, and assumption audits.
- `validate-science` - Validate ExoSwarm numerical astronomy behavior against controlled fixtures, cached real TESS observations, expected ranges, units, and tolerances.
- `verify-integration` - Verify ExoSwarm end to end across scientific tools, evidence, investigation state, agent decisions, APIs/SSE, frontend rendering, and lock invariants.
